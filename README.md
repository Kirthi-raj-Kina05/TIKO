# Habit Tracking App

A modern **Habit Tracking application** designed to help users build positive habits, maintain consistency, and monitor their daily progress through a clean and intuitive user interface.

✨ Features

- 📅 Track daily habits and routines
- 📊 Monitor habit progress and consistency
- 🔥 Maintain streaks and build motivation
- 🎯 Set and manage personal goals
- 📱 Clean, responsive, and user-friendly design
- 🎨 Modern UI based on the Figma design

🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- React *(if applicable)*
- TypeScript *(if applicable)*

🎨 Design

The application's UI/UX was designed in **Figma**, with a focus on simplicity, accessibility, and an engaging habit-tracking experience.

Figma Design:
https://www.figma.com/design/ERzHrvyvR0G0bzuC3kcfWK/Habit-Tracking

🚀 Goal

The goal of this project is to create a simple yet effective digital habit tracker that makes it easier for users to develop positive routines, visualize their progress, and stay consistent over time.
